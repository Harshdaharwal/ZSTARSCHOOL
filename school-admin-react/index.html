If this screen does not go away, you are probably opening the source index.html with Live Server or from disk. That file must be served by Vite (it compiles React).

  1. Open a terminal in the school-admin-react folder.
  2. Run npm install (once), then npm run dev.
  3. Open http://localhost:5173/

For a static build: npm run build, then open dist/index.html (use hash URLs like #/login if links look wrong on a simple static server).
